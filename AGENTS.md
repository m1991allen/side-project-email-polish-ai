# Project handbook & skills

Before starting work, skim the handbook and pick the skill that matches the task:

- Handbook (architecture, env, cross-file contracts, known gaps): [`.claude/HANDBOOK.md`](.claude/HANDBOOK.md)
- Skills index (workflow-per-task): [`.claude/skills/README.md`](.claude/skills/README.md)

Skills are workflows, not reference docs. Open the relevant `SKILL.md`, treat its `Process` block as a checklist, and walk its `Verification` block before declaring the task done.
